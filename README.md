# Disable Projectile Rendering
This mod allows you to granularly tweak and control what kinds of projectiles are rendered, which can, in some cases, give a significant performance boost when there are hundreds of projectiles being rendered.

You may need [Sodium](https://modrinth.com/mod/sodium) or [More Culling](https://modrinth.com/mod/moreculling) for this, I'm not entirely sure as I didn't test with either. 
All I know is that with the vanilla renderer still "renders" the projectiles even though you can't see them.

## Newly-added/modded projectiles
They should be covered by the "Other" projectiles category. If not, please make an [issue](https://github.com/supafridge/Disable-Projectile-Rendering/issues) and let me know.

## Configuring
Note that you also need Sodium to granularly configure the individual projectiles that have their rendering disabled.
You can set keybinds for the projectile categories, but it's not as granular.
